# v1.0.0 — Plugin Architecture Rebuild

**Date**: 2026-05-16
**Linear feature**: [PMO-71 — `[SPEC] 001: Plugin Architecture Rebuild`](https://linear.app/pmo-to-do-list/issue/PMO-71/spec-001-plugin-architecture-rebuild)
**Upstream tracker**: `github/spec-kit v0.8.10` (pinned in `.specify/upstream.pin`)
**Commits**: `b3aae2b..HEAD` on `upstream-sync-0.8.10` (PR [#1](https://github.com/derobiwan/speckit-linear/pull/1))

This release rebuilds `speckit-linear` onto upstream `github/spec-kit`'s plugin architecture. The 11 user-facing `/speckit.*` slash commands keep their names; everything underneath them is new.

## Headline changes

- **Plugin model**: behaviour split into an unmodified upstream CLI + a `extensions/linear/` extension (the Linear MCP boundary) + a `presets/linear/` preset (wraps the 11 core templates). Constitution P1 forbids local patches to `src/specify_cli/`.
- **30 supported AI agents** (was 5). Install path: `specify init --ai <name> --preset linear --extension linear`.
- **Idempotent artifact persistence**: every command calls `save_issue` with the existing id when a matching `feature:NNN-name + speckit:<type>` pair already exists (FR-031).
- **Bounded retries** on every Linear MCP call (3 attempts, 1s/2s/4s ±25% jitter, 5xx/429/timeout only; FR-032) plus full JSON-Lines logging at `.specify/logs/linear-mcp.log` (10 MB rotation, secrets scrubbed; FR-034).
- **`specify upgrade-from-v051`**: idempotent archive of legacy v0.5.1 directories under `.specify/legacy-v051/<ISO-timestamp>/`. Linear data untouched.
- **Upstream-sync CI gate**: any drift in vendored directories fails the build (Constitution P1, FR-013/FR-014).

Full breaking-change list: [`CHANGELOG.md`](../../CHANGELOG.md) § `[1.0.0]`.
